# 📚 Електронний шкільний щоденник

Повноцінний веб-додаток для керування домашніми завданнями на чистому PHP з базою даних JSON.

## 🚀 Технології

- **PHP** (без фреймворків)
- **JSON** файли як база даних
- **HTML5 + CSS3** з glassmorphism дизайном
- **Адаптивна верстка** (mobile-first)

## 📁 Структура проекту

````
/
├── data/
│ ├── users.json # База користувачів
│ └── homework.json # База домашніх завдань
├── includes/
│ ├── auth.php # Система авторизації
│ └── db.php # Робота з JSON базою
├── login.php # Сторінка входу
├── register.php # Сторінка реєстрації
├── logout.php # Вихід із системи
├── dashboard.php # Головна сторінка з ДЗ
├── add_homework.php # Додавання ДЗ
└── style.css # Стилі програми
````

## 🎯 Функціонал

### Ролі користувачів:
- **Student (Учень)** - перегляд домашніх завдань
- **Teacher (Вчитель)** - перегляд та додавання ДЗ
- **Admin (Адміністратор)** - повний доступ

### Можливості:
- ✅ Реєстрація та авторизація
- ✅ Безпечне зберігання паролів (password_hash)
- ✅ Керування домашніми завданнями
- ✅ Фільтрування ДЗ за класами
- ✅ Сортування за дедлайном
- ✅ Індикація прострочених завдань
- ✅ Адаптивний дизайн для мобільних

## 🛠️ Встановлення та запуск

### Вимоги:
- PHP 7.4 або вище
- Веб-сервер (Apache/Nginx) або вбудований PHP-сервер

### Швидкий старт:

1. **Клонуйте проект:**
``` bash
cd /home/natisk/Документи/Rozrobka-reborn
````

2. **Запустіть вбудований PHP сервер:**
``` bash
php -S localhost:8000
````

3. **Відкрийте у браузері:**
````
http://localhost:8000/register.php
````

4. **Створіть першого користувача:**
   - Зареєструйтесь з роллю "Учитель" або "Адміністратор"
   - Увійдіть у систему

## 👥 Тестові дані

Після реєстрації створіть користувачів із різними ролями:

**Вчитель:**
- Логін: teacher
- Пароль: teacher123
- Роль: Teacher

**Учень:**
- Логін: student
- Пароль: student123
- Роль: Student

## 🎨 Дизайн

Додаток використовує сучасний **glassmorphism** стиль:
- Темна тема із градієнтами
- Прозорі картки з ефектом blur
- Плавні анімації та переходи
- Адаптивна верстка для всіх пристроїв

## 🔒 Безпека

- Паролі хешуються через `password_hash()`
- Перевірка через `password_verify()`
- Захист від несанкціонованого доступу
- Перевірка ролей на рівні PHP

## 📱 Адаптивність

Програма повністю адаптована для:
- 📱 Мобільних пристроїв (від 360px)
- 📱 Планшетів (768px+)
- 💻 Десктопів (1200px+)
